# Math Quiz Game

A console-based Math Quiz Game developed in C++ as part of my Algorithms & Problem-Solving learning journey.

## Overview

This project is a simple interactive math quiz game where the player can choose the number of questions, difficulty level, and arithmetic operation to practice.

The game generates random questions, checks the player's answers, tracks the score, and displays the final results.

## Features

- Choose the number of questions
- Multiple difficulty levels:
  - Easy
  - Medium
  - Hard
  - Mixed
- Multiple arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Mixed
- Random question generation
- Automatic answer validation
- Correct and incorrect answer tracking
- Final score and performance evaluation
- Input validation
- Play again functionality
